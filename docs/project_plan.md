# CityFlow Vehicle Tracking — 구현 계획

> v0.3 · 2026-11-03 · 진행 중

## 목표

**CityFlowV2에서 차량을 추적하고 다른 카메라의 동일 차량을 검색하며, 논문의 핵심 방법을 직접 구현·비교한다.**

먼저 YOLO11s를 고정 검출기로 사용해 ByteTrack과 TransReID 실험을 진행한다. 이후 YOLO-MS의 MS-Block을 구현하고 탐지 확장을 검토한다.

## 구현 범위와 진행 순서

| 단계 | 구성 | 직접 작성할 부분 | 완료 결과 |
| --- | --- | --- | --- |
| 준비 | YOLO11s | 영상·GT 처리, 검출 결과 저장 | 박스·신뢰도가 저장되고 탐지 영상을 재생할 수 있음 |
| **1차: 추적** | YOLO11s + ByteTrack | **고·저신뢰도 2단계 매칭, 트랙 상태 관리** | 차량 ID·궤적 시각화, 2차 매칭 유무 비교 |
| **2차: 검색** | YOLO11s + ByteTrack + TransReID | **차량 이미지 수집, 특징 결합, 유사도 검색** | 2~3개 카메라에서 동일 차량 후보 검색, 단일/여러 프레임 비교 |
| **3차: 탐지 구조** | YOLO-MS | **MS-Block 부분 구현** | 공식 구현과 구조·출력 형태·동일 가중치 조건의 수치 비교 |

**활용 범위:** YOLO11s·TransReID의 모델/가중치와 표준 연산 라이브러리는 재사용한다. ByteTrack의 핵심 로직과 MS-Block은 직접 작성한다. 직접 작성·외부 활용 범위를 코드와 문서에 명시한다.

**시스템 참고:** *Multi-Camera Vehicle Tracking System for AI City Challenge 2022*는 위 과정의 구성·카메라 간 연결 전략을 참고하는 논문이다. 별도의 4차 개발 단계는 아니다.

## 설계

| 처리 | 입력 → 출력 |
| --- | --- |
| 탐지 | 카메라 영상 → 프레임별 차량 박스·신뢰도 |
| 추적 | 연속 프레임의 검출 결과 → 카메라 내부 차량 ID·궤적 |
| 특징 추출 | 같은 추적 ID의 차량 이미지 묶음 → TransReID 특징 벡터 |
| 검색 | 조회 차량 특징 + 다른 카메라의 후보 특징 → 유사도순 차량 후보 |

검색은 후보를 제시하는 기능부터 완성한다. 시간·카메라 관계를 이용한 자동 궤적 연결은 후속 확장으로 둔다. YOLO-MS를 통합할 때는 사용할 전체 모델과 가중치를 검증하고 탐지기 교체 전후를 비교한다. MS-Block 구현만으로 탐지기를 교체하지 않는다.

## 검증할 것

| 실험 | 고정 조건 | 바꿀 것 / 확인할 결과 |
| --- | --- | --- |
| ByteTrack | 같은 검출 파일·평가 영상 | 2차 매칭 켜기/끄기 → IDF1·ID 변경·궤적 단절 |
| 차량 검색 | 같은 TransReID 가중치·조회/후보 구성 | 대표 프레임 1장/여러 프레임 특징 결합 → Rank-1·검색 mAP |
| MS-Block | 같은 구조·가중치·입력·평가 모드 | 직접 구현/공식 구현 → 출력 형태·수치 오차 |

공식 train/validation/test 분할을 유지하고 비교용 validation subset을 먼저 고정한다. GT는 모든 차량을 포함하지 않으므로 공식 평가 도구의 필터링·제외 규칙을 확인한다. 검색에서는 동일 카메라 제외 규칙과 가중치 학습 데이터의 중복 여부를 확인한다. 실험마다 설정·Git commit·지표·실패 사례를 기록한다.

## 현재 상태와 다음 작업

- **완료:** 데이터 구조 확인, 영상 정보 조회, 지정 프레임 GT 시각화 및 샘플 확인.
- **다음:** YOLO11s로 저신뢰도 박스까지 보존한 검출 입력 준비 → ByteTrack Algorithm 1 분석·구현.
- **첫 완료 목표:** 카메라 하나에서 ByteTrack을 직접 구현하고, 같은 검출 입력으로 2차 매칭 유무를 비교한 결과를 남긴다.

초기 범위: 저장된 영상·카메라 1개에서 시작해 2~3개로 확장. 전체 검출기 처음부터 학습, 대회 시스템 전체 재현, 실시간 연동·웹 배포는 초기 범위에 포함하지 않는다.
